## 2. 开通腾讯云 OCR 身份证识别功能

### 步骤 1：登录腾讯云控制台
1. 访问 [腾讯云控制台](https://console.cloud.tencent.com/)
2. 使用你的腾讯云账号登录

### 步骤 2：开通文字识别服务
1. 进入 **产品** → **人工智能** → **文字识别 OCR**
2. 或直接访问：[文字识别控制台](https://console.cloud.tencent.com/ocr)
3. 点击 **立即开通**
4. 阅读并同意服务协议

### 步骤 3：申请身份证识别权限
1. 在左侧菜单选择 **身份证识别**
2. 点击 **申请开通**
3. 按照提示完成实名认证（如未完成）
4. 等待审核通过（通常即时生效）

### 步骤 4：创建 API 密钥
1. 进入 **访问管理** → **[API 密钥管理](https://console.cloud.tencent.com/cam/capi)**
2. 点击 **新建密钥**
3. 系统会生成一对 SecretId 和 SecretKey
4. **立即保存** 这两个密钥，SecretKey 只会显示一次！

## 3. 项目配置

### 方式一：环境变量配置（推荐）
在 `.env` 文件中添加以下配置：

```bash
# 腾讯云 OCR 身份证识别配置
TENCENT_OCR_SECRET_ID=你的SecretId
TENCENT_OCR_SECRET_KEY=你的SecretKey
TENCENT_OCR_REGION=ap-beijing  # 默认北京，可改为 ap-shanghai 等
```

### 方式二：application.yml 配置
在 `shiyiju-user/src/main/resources/application.yml` 中添加：

```yaml
# 腾讯云 OCR 配置
tencent:
  ocr:
    secret-id: ${TENCENT_OCR_SECRET_ID:}
    secret-key: ${TENCENT_OCR_SECRET_KEY:}
    region: ${TENCENT_OCR_REGION:ap-beijing}
```

腾讯云 OCR 身份证识别采用 **按量计费**：

| 服务类型 | 免费额度 | 单价 | 说明 |
|---------|---------|------|------|
| 身份证识别 | 1000次/月 | 0.15元/次 | 每月前1000次免费 |

**计费规则**：
- 每月有 **1000次免费额度**
- 超出部分按 **0.15元/次** 计费
- 支持 **后付费**，按实际调用量计费
- 可购买 **资源包** 享受折扣

- 接口名称：`IDCardOCR`

## 7. 注意事项

### 安全建议
1. **密钥安全**：SecretKey 不要提交到代码仓库
2. **环境隔离**：开发、测试、生产环境使用不同的密钥
3. **权限控制**：使用子账号密钥，遵循最小权限原则

### 技术建议
1. **图片质量**：建议使用清晰、正面拍摄的身份证图片
2. **图片大小**：建议图片文件小于 5MB
3. **Base64 处理**：前端需去除 `data:image/jpeg;base64,` 前缀
4. **错误处理**：代码已处理"服务未开通"、"未授权"等错误

### 监控与告警
1. **监控调用量**：在控制台查看调用统计
2. **设置告警**：当调用量异常或费用超预算时告警
3. **日志记录**：记录每次识别的结果和耗时

## 9. 常见问题

### Q2: 免费额度是多少？
A: 每月 1000 次免费调用，超出后按 0.15元/次计费。

### Q3: 支持哪些身份证类型？
A: 支持中国大陆居民身份证正反面识别。

### Q4: 响应时间多久？
A: 通常在 1-3 秒内返回结果。

### Q5: 如何查看调用统计？
